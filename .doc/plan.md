# План подготовки репозитория ID_Thread_Fix к публикации на GitHub

## Цель проекта
**ID_Thread_Fix (InDesign Thread Fix)** — легковесная утилита для Windows, решающая критическую проблему Adobe InDesign (версий 2020–2026+), при которой фоновые потоки (CEP, синхронизация CC, кэши шрифтов) зацикливаются и загружают процессорное ядро на 100%, вызывая перегрев, шум кулеров и лаги интерфейса. Утилита безопасно обнаруживает и завершает только зацикленные фоновые потоки, гарантированно защищая UI-поток и основной рабочий процесс InDesign.
