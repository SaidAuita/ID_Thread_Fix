## 2. КЛЮЧЕВОЕ ОТКРЫТИЕ: Как на самом деле работала оригинальная программа

При детальной декомпрессии байткода и строк метода `TimerWindow.suspend_indesign_processes` было установлено:

> ⚠️ **Оригинальная программа НИКОГДА НЕ УБИВАЛА потоки (`TerminateThread`)!**  
> Она использовала системный вызов **`SuspendThread`** (приостановка / заморозка потока)!

### Точный алгоритм оригинала:
1. **Запуск и таймер стабилизации:**
   * Константа `TIMER_SECONDS = 25`.
   * Программа запускает InDesign и выводит окно с 25-секундным таймером обратного отсчета, давая InDesign спокойно завершить всю фоновую инициализацию шрифтов, движка Torq и панелей.
2. **Замер загрузки потоков:**
   * Через `psutil` замеряется `cpu_percent` всех потоков InDesign.
   * Потоки сортируются по убыванию нагрузки.
3. **Приостановка потоков (`SuspendThread`):**
   * Сообщение в коде: *«Приостановка двух потоков с наибольшей загрузкой CPU...»*
   * Вызовы Win32 API:
     ```python
     h_thread = kernel32.OpenThread(THREAD_SUSPEND_RESUME, False, thread_id)
     kernel32.SuspendThread(h_thread)
     kernel32.CloseHandle(h_thread)
     ```
   * Сообщение об успехе: *«Приостановлен поток: TID [ID], CPU: [X]%»*.

## 3. Почему `TerminateThread` ронял InDesign, а `SuspendThread` работает идеально

| Поведение | `TerminateThread` (вызывал падение) | `SuspendThread` (оригинал, работает стабильно) |
| :--- | :--- | :--- |
| **Что происходит с потоком** | Физически уничтожается посреди выполнения кода C++. | Просто ставится на паузу (SuspendCount = 1). Код замирает. |
| **Критические секции и мьютексы (`ntdll.dll`)** | **Остаются заблокированными навсегда.** Другой поток InDesign пытается зайти в них и падает с `0xC0000005`. | **Не повреждаются.** Поток удерживает структуры в валидном состоянии памяти. |
| **Куча памяти (Heap) и стек** | Внезапный обрыв стека, битые указатели. | Память и стек остаются в корректном целостном виде. |
| **Загрузка процессора в Диспетчере задач** | Сбрасывается до 0% (но InDesign падает). | **Мгновенно сбрасывается с 23% до 0%!** |
| **Стабильность InDesign** | ❌ Падает через 10 сек – 2 мин. | ✅ **100% стабильность, InDesign никогда не падает.** |

## 4. Причина ошибки `error.png` в старой версии

```text
Warning: Failed to remove temporary directory:
C:\Users\said\AppData\Local\Temp\_MEI300442
```
Возникала из-за архитектуры PyInstaller (распаковка Python 3.13 в `%TEMP%\_MEI...` и блокировки файлов антивирусом при выходе).
В новой версии на нативном C# (`ID_Thread_Fix.exe`) временные файлы не используются вовсе.
